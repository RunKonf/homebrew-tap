# homebrew-tap

Homebrew tap for [Konf](https://konf.app) CLI tools.

## Usage

```sh
brew tap RunKonf/tap
brew install konf
```

## Formulae

| Formula | Description                                |
| ------- | ------------------------------------------ |
| `konf`  | CLI for Konf - Run your conference. |

Formulae are automatically updated on each [konf release](https://github.com/RunKonf/konfctl/releases).
